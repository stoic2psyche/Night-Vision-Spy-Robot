# Night-Vision-Spy-Robot
A Wi-Fi-enabled night vision spy robot using ESP32-CAM and NodeMCU for real-time video streaming, remote control, and obstacle detection.
## 🚀 Features

- 📷 Real-time video streaming (ESP32-CAM)
- 🌙 Night vision capability using IR LEDs
- 📡 Remote control via NodeMCU-hosted web server
- 🚧 Obstacle detection with ultrasonic sensors
- 🔋 4-wheel drive with L298N motor driver

## 🧰 Hardware Components

- ESP32-CAM
- NodeMCU ESP8266
- L298N Motor Driver
- HC-SR04 Ultrasonic Sensors
- IR LEDs
- 4× DC Motors
- Battery or power supply
- Chassis and wheels

## 💻 Software Tools

- Arduino IDE
- ESP32 & ESP8266 board libraries
- HTML/CSS for web interface
- Serial Monitor for debugging

##  How It Works

1. ESP32-CAM streams video via local IP.
2. NodeMCU serves a control webpage to move the robot.
3. Ultrasonic sensors detect obstacles in front.
4. L298N drives the motors based on user input.

## Future Improvements

- Object detection or tracking with AI
- Better IR LEDs for clearer night vision
